# AI SQL Query Generator

An AI-powered application that converts
natural language requirements into SQL queries.

Features:

- SQL Query Generation
- Query Explanation
- Sample Output
- Query Optimization
- Download SQL
- Gemini AI Powered

Tech Stack:

- Python
- Streamlit
- Gemini API

Supported SQL Operations:

- SELECT
- INSERT
- UPDATE
- DELETE
- JOIN
- GROUP BY
- ORDER BY
- HAVING
- Subqueries
